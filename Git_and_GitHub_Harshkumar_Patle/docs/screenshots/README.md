# Screenshot evidence folder

Capture real screenshots on your Linux machine and save them here using the filenames in `../assignment_report.md`.

Suggested tools:
- Ubuntu: `PrtSc` / `Shift+PrtSc`
- Terminal screenshot: use your desktop screenshot utility.
- Save screenshots as PNG files.

Do not put private SSH keys, `.env` files, passwords, or MongoDB credentials in screenshots. Public SSH keys are okay to add to GitHub but should not be included in the ZIP unless needed.
